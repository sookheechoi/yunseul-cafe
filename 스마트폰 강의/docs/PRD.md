# 사이트 설계도(PRD) — 스마트폰 활용 클래스 (사이트 이름 미정)

작성일: 2026-10-27 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
회사·단체를 찾아가서 하는 스마트폰 활용 출강 수업을 소개하고, 강의 문의를 받는 사이트.

## 2. 손님
- 누가: 회사·단체의 교육 담당자 (직원·회원 교육을 맡은 사람)
- 어디서 알고 오나: 네이버·구글 검색, 지인·기관 소개, 블로그·SNS, 명함·제안서 QR

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의 주제·커리큘럼 — 어떤 내용을 몇 회에 걸쳐 가르치는지
2. 강사료·비용 — 시간당 금액
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 강의 현장 사진 (사용자가 가진 실제 사진을 넣는다)
- 출강한 기관 목록 (사용자가 알려 준 이름만 넣는다 — 지금은 목록 미정)
- 후기: 실제 수강 후기가 있음 (사용자가 준 문장 그대로 넣는다 — 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 강의 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + [강의 문의하기] 버튼
2. 강의 주제·커리큘럼
3. 강사료 (시간당 금액) + 진행 방식
4. 강의 현장 사진 + 출강한 기관 목록
5. 수강 후기 (실제 후기만, 없으면 비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 예상 인원 · 희망 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 사이트 이름: (미정)
- 가격: 시간당 금액으로 표시 — 금액 (미정)
- 시간: (미정)
- 위치(출강 지역): (미정)
- 연락 방법: 문의 폼 (전화·메일 등 그 밖의 연락처는 미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제
- 사진 올리기(문의 폼 첨부)
- 알림 메일
- 블로그·게시판

## 10. 첫 화면 한 문장 후보
1. 직원 교육, 스마트폰 활용부터 시작하세요 — 찾아가는 맞춤 강의
2. 우리 회사에 맞춘 스마트폰 활용 교육, 강사가 직접 찾아갑니다
3. 오늘 배워 내일 바로 쓰는 스마트폰 활용 출강 수업

## 11. 다음에 할 것
- 사이트 이름, 시간당 강사료, 출강 지역, 연락처 채우기
- 출강 기관 목록과 실제 후기 문장 받아서 넣기
- 회원가입·로그인 (필요해지면 개인정보 처리방침과 함께)
- 강의 제안서(PDF) 내려받기
- 문의가 오면 알림 메일

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
