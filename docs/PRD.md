# 사이트 설계도(PRD) — 윤슬처럼

작성일: 2026-10-27 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
모임 장소를 찾는 총무가 분위기·메뉴·위치를 보고, 날짜·인원·예산·메뉴 선택을 남겨 단체석을 문의하는 카페 '윤슬처럼'의 사이트.

## 2. 손님
- 누가: 모임 장소를 찾는 총무 (동호회·동창회·회사 모임 등을 챙기는 사람)
- 어디서 알고 오나: 인스타그램, 네이버 검색·지도, 지인 소개·단골, 그 밖의 경로(미정)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 몇 명까지 앉을 수 있나 (단체석 크기)
2. 1인당 예산·메뉴 가격
3. 주차·찾아오는 길

## 4. 믿게 할 증거 (실제로 있는 것만)
- 매장·단체석 사진
- 메뉴 사진
- 후기: 실제 모임 후기 (사장님이 가진 실제 후기만 넣는다. 지어내지 않는다)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 단체석 자리 확인하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 장)
1. 첫 화면 — 한 문장 + [단체석 자리 확인하기] 버튼
2. 분위기 — 매장·단체석 사진, 몇 명까지 앉는지
3. 메뉴 — 메뉴 사진과 가격대, 1인당 예산 감
4. 오시는 길 — 주소, 지도, 주차 안내
5. 실제 모임 후기
6. 문의 폼 (단체석 자리 확인하기)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 모임 날짜
- 인원
- 1인당 예산
- 메뉴 선택: 미리 고르기 / 현장에서 고르기
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 단체석 최대 인원: 15명
- 가격: 수제대추차 7,000원 · 샌드위치 7,500원 · 아메리카노 4,000원 · 1인당 예산 약 1.5만 원
- 영업시간: 매일 10:00 – 22:00
- 위치: 경기 부천시 소사구 소삼로 47-1 (소사역 소사푸르지오아파트 상가 B동 103호) · 소사역 4번 출구 도보 5분
- 주차: 가능
- 연락 방법: 032-351-5100
- 실제 모임 후기: (아직 없음 — 사이트에서 후기 칸은 숨겨 둠)
- 개인정보 보관 기간: 1년 (임시, 사장님 확인 필요)

## 9. 이번에 넣지 않을 것
- 결제·예약금
- 회원가입·로그인
- 사진 올리기
- 알림 메일·문자
- 실시간 빈자리(달력) 확인

## 10. 첫 화면 한 문장 후보
1. 우리 모임, 윤슬처럼 따뜻한 자리에서.
2. 총무님, 모임 장소 고민은 여기서 끝내세요.
3. 날짜와 인원만 남겨 주세요. 자리는 저희가 확인해 드릴게요.

## 11. 다음에 할 것
- 사진 교체: 직접 찍은 사진 또는 허락받은 사진으로 (매장·단체석·메뉴 3장)
- 실제 모임 후기가 생기면 후기 칸 다시 보이기
- 손님 받기 전: 관리자 비밀번호를 더 안전한 것으로 바꾸기
- 개인정보 보관 기간 확정 (지금은 1년)
- 예약금·결제
- 문의 들어오면 알림(메일·문자)
- 빈자리 달력
- CSV 내려받기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
  - 관리자 기능: 문의 목록 보기 · 상태 바꾸기(새 문의 → 연락함 → 완료) · 48시간 넘은 문의 알림
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
